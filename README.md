# Optimization-Visualization
Types of optimization utilized:

Particle Swarm Optimization: Taking a large collection of randomized points on a surface and having them move through each iteration with a direction composed of a random element and the lowest position any particle has reached.

Gradient Ascent/Descent: Taking a point on a function and finding relative maxima/minima by following a positive/negative gradient, and ending when it reaches a gradient of 0, a guaranteed extrema.

Hill Climb: Taking a point on a surface, and finding the values of the surrounding points. Moves to the highest measured position.

Simulated Annealing: Similar to PSO, but taking one single point and allowing it to move with a randomized component and a component weighted towards lowest/highest point reached, allowing absolute maxima/minima to be located with less total calculations.
